# XAUUSD 経済指標AI予測・検証・研究システム

米国経済指標の発表時にゴールド（XAUUSD）がどう動くかを予測し、発表後の実績と比べて検証し、その結果を次の予測の材料にする研究用Webアプリです。自動売買は行いません。

```
今後の指標 → 事前予測（バージョン管理・上書き禁止） → 発表時刻を過ぎたら自動で過去側へ
→ 価格データ取込 → 実績算出・誤差計算 → 検証レポート（事実と仮説を分離） → 研究室・精度ダッシュボード
```

## 構成

| 層 | 技術 |
|---|---|
| フロントエンド | Next.js 15 / TypeScript / Tailwind CSS / TradingView Lightweight Charts（日本語・ダークテーマ・レスポンシブ） |
| バックエンド | Python / FastAPI / SQLAlchemy 2 |
| DB | PostgreSQL 16 |
| 分析 | Pandas / NumPy（統計ベースライン）。scikit-learn / LightGBM は Phase 3〜4 で使用予定 |
| 定期処理 | APScheduler（既定は60秒ごとにステータス更新と自動検証） |
| AI | Anthropic Claude API（任意。`ANTHROPIC_API_KEY` を設定したときだけ、検証レポートに仮説を追加） |

## 起動方法

### Docker Compose

```bash
docker compose up --build
# フロント http://localhost:3000 / API http://localhost:8000/docs
```


## 画面

- **ホーム**: 次の重要指標とカウントダウン、最新AI予測、今週の指標、直近の結果、予測精度、研究状況、データ取得状況
- **今後の指標**: 未来のイベントのみ表示。重要度、前回値、コンセンサス、AI予想、方向確率、最大変動幅、5分後終着地、最終更新日時
- **過去の指標**: 予測と実績、誤差、反省、改善点。未検証の記録には「未検証」と表示
- **イベント詳細**: 指標数値の編集（実績は公式の出所を入れたときだけ「照合済み」にできる）、予測バージョン一覧と予測フォーマット4-1〜4-7、チャート、実績、全バージョンの比較、検証レポート、類似イベント
- **AI研究室**: 指標別の値幅分布（検証済みと未検証は別表示）、反転パターン、蓄積された教訓
- **予測精度**: 方向正答率、5分後MAE、最大変動幅MAE、指標数値の誤差、Brierスコア、確率の校正、指標別・モデル別成績、改善履歴、モデル登録簿
- **データ**: TradingView CSVインポート、データソースの状態、保有範囲、インポート・ジョブ履歴

## データの信頼性ルール（実装で強制しているもの）

- **予測は不変**: `forecast_versions` は ORM と PostgreSQL のトリガーの両方で UPDATE と DELETE を禁止しています。修正は新しいバージョンとして追加します。
- **発表後の情報を混ぜない**: 予測時点が発表時刻以降の予測や、予測時点より後に公開されたニュースを使った予測は保存を拒否します。統計ベースラインは予測時点より前に発表された、検証済みイベントだけを使います。
- **整合性チェック**: 方向確率の合計は100%。到達確率は値幅が大きいほど下がること（単調非増加）、「どちらか」の確率は片方向以上、「両方」の確率は片方向以下。30分・60分レンジが短い時間幅のレンジより小さくならないこと。
- **項目を混同しない**: 終着地（dN）、5分間の最大上昇幅・最大下落幅、最大到達幅、高値安値レンジは別々の項目です。時間幅が分からない値は `headline_move` や `extras` に入れ、`comparable=false` として参考扱いにします。
- **確定と暫定を分ける**: 会話由来の記録は `verified=false`。精度ダッシュボードは「確定」と「暫定」を別々に集計し、ベースライン学習には確定データだけを使います。
- **検証完了の条件**: 価格データから実績を算出でき（発表直前・5分後・5分間の高値安値）、かつ全指標の実績が公式の出所付きで照合済みであること。条件を満たさないイベントは `awaiting_data` または `historical_unverified` のまま残り、あとから再検証できます。イベントは削除しません。
- **ニュースURL**: 分からない場合は NULL のまま保存し、補完しません。

## 初期データ（ChatGPTとの会話記録）

`backend/app/seed/conversation_2026.py` に2026年9〜10月の記録を登録しています。すべて未検証です。

- 発表時刻は会話に記録がないため、米国の通常スケジュールから推定しています（`時刻未確定` と表示）。FOMC議事要旨は会話上の日付が10月7日で、日本時間10月8日03:00と推定しています。
- 9/30 は ADP（21:15）と PCE等（21:30）の2つのイベントに分け、同じ `cluster` で関連付けています。
- ISM は発表日時と製造業・非製造業の区別が不明なので、日時なしの独立した記録として登録しています。
- 10/29 の FOMC（議長会見は子イベント）と GDP＋PCE は、Ver.1〜3 を未来のイベントとして登録しています。
- NFP の2つ目のバージョン（+11万人・−25ドル）は、組み合わせが会話上で確定していないことをメモに残しています。

## 発表後の検証手順

1. TradingView で XAUUSD の **1分足** をエクスポートし、「データ」画面から取り込みます。初動と反転の判定には1分足が必要です。DXY・US02Y・US10Y も同じ方法で取り込めます。
2. 取込後に自動検証が走り、価格データから算出した実績（会話記録とは別のレコード）、全バージョンの評価、検証レポートが作られます。
3. イベント詳細で指標の実績と公式の出所を入力し、「公式データと照合済み」にチェックして「検証を実行」を押すと、ステータスが `verified` になります。
